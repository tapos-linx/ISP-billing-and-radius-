# UI Specification: ISP Billing System

## 1. Color Palette
- **Deep Space**: `#0B132B` (Background)
- **Navy Blue**: `#1C2541` (Surface/Cards)
- **Cyan Pulse**: `#48CAE4` (Primary/Action)
- **Emerald SLA**: `#06D6A0` (Success/Online)
- **Amber Warning**: `#FFD166` (Pending/Warning)
- **Crimson Alert**: `#EF476F` (Critical/LOS)

## 2. Typography
- **Headings**: Inter (Bold)
- **Data/Code**: JetBrains Mono

## 3. Layout Modules
1. **NOC Command Center**: High-density grid with real-time charts (Recharts).
2. **Subscribers List**: Paginated table with shard badges and quick-action drawers.
3. **VSA Editor**: Syntax-highlighted text areas for vendor configs.
4. **ACS Console**: Device-centric view with signal strength meters.
5. **Billing Lab**: Interactive form for testing HMAC signatures and webhook idempotency.
6. **Hardware Exporter**: Multi-tab code viewer with copy-to-clipboard functionality.
